Key Concepts

This page goes over a few terms that help explain how HTTP works.

  • Client-Server Model: A system where a client requests information and a server provides it.
  • Request: A message sent by the client asking for a webpage, file, or service.
  • Response: The server's reply, which may include a webpage, image, data, or error message.
  • Status Codes: Standard numbers such as 200, 404, and 500 that describe the result of a request.
  • Headers: Extra information included with requests and responses, such as content type or caching rules.
  • HTTPS: The secure version of HTTP that encrypts data during communication.
  • API: A way for programs and services to communicate using HTTP methods and web-based data exchange.
