## How to upload
1. Open your existing GitHub repo from milestone 1.
2. Upload these files into the root folder of the repo.
3. Replace older versions of the matching files.
4. Commit the changes.
5. Make sure GitHub Pages is still publishing from the root/main branch.
6. Test the live link and click through every page, especially quiz.html.
