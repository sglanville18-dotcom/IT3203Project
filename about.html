Project notes

This page summarizes the design choices and milestone 2 updates in a direct way.

Project purpose

This website was built for IT 3203 to explain HTTP in a way that is easier to follow than a dense technical write-up. The goal was to keep the pages readable, use a consistent menu, and add a working JavaScript feature instead of making the site completely static.

What changed in milestone 2

  • Added a separate quiz page with form controls and JavaScript grading
  • Improved layout and changed section wording so pages feel less repetitive
  • Expanded content on methods, status codes, statelessness, APIs, and HTTPS
  • Updated the menu on every page
  • Cleaned up CSS and added comments in the code

Design approach

I did not want the site to look like a plain starter template, so the sections use different layouts, quick-note boxes, and page-specific headings. The quiz wording also matches the actual site content instead of using random facts.
